# 비서 — 배포본

개인용 일정 비서의 **실행파일과 업데이트 메타데이터만** 두는 곳이다.
소스 코드는 비공개 저장소에 있다.

여기가 공개인 이유는 하나다 — 앱의 자동 업데이트가 `latest.json` 을
인증 없이 읽어야 해서다. 비공개 저장소로는 구조적으로 불가능하다.

## 설치

[Releases](../../releases/latest) 에서 `biseo_*_x64-setup.exe` 를 받아 실행한다.
그 뒤로는 새 버전이 나오면 앱이 직접 알려준다.

## 쓰려면

API 키는 들어 있지 않다. AI 기능은 각자 자기 키(Claude / Gemini)를 넣거나
ChatGPT 계정으로 로그인해야 돈다. 넣은 키는 그 기기에만 저장된다.
